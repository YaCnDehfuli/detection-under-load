# Security policy

Report vulnerabilities in this repository privately to
**dehfouliyasin@gmail.com**. Please do not open a public GitHub issue for
exploitable findings.

There is no bug bounty.

This is a Sigma evaluation harness and a measured study, not a SIEM.
Reports about the evaluator, committed rules, or corpus-handling code
are in scope. I will acknowledge reports as soon as I can.
